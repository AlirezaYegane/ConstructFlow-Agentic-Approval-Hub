# ConstructFlow Agentic Approval Hub

ConstructFlow is a governed AI-assisted approval workflow for construction operations.

## Problem
Construction teams often manage defects, variations, and safety issues through fragmented communication and inconsistent approval paths.

## Solution
ConstructFlow provides:
- structured request intake
- governed approval actions
- controlled document generation
- audit visibility
- dashboard monitoring

## Core flow
1. Submit request
2. Review request details
3. Approve or reject
4. Generate controlled document
5. Inspect audit trail
6. Monitor dashboard

## Stack
- Next.js
- TypeScript
- Tailwind CSS
- FastAPI
- SQLAlchemy
- SQLite
- ReportLab
